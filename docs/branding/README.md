# EduNexus logo

The approved identity is concept 01 from the upper row: the unboxed, twisted
hidden-F mark in brushed silver, dark titanium and fine copper edging.

`edunexus-titanium-master.png` is the transparent, full-resolution raster master.
It was extracted using the built-in image generation editor from the approved
comparison artwork. The extraction prompt preserved the first symbol's geometry,
metallic finish and palette, removed the board and text, and requested a genuine
transparent background with no rounded-square tile or cast shadow.

Application exports:

- `frontend/public/edunexus-mark.png`: 256px shared UI mark.
- `frontend/public/icon-192.png` and `icon-512.png`: web app icons.
- `frontend/app/favicon.ico`: browser icon in multiple sizes.
- `android-app/res/mipmap-xxxhdpi/ic_launcher.png`: 192px Android launcher asset.
- `desktop-client/assets/icon.png` and `icon.ico`: desktop window/build icons.

Keep the background transparent when exporting. Do not add a black tile or
replace the approved mark with a literal letter. The existing application theme
is independent of the logo; wordmark accents use copper tones in both modes.
